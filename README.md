Catch the Stars

Description
A casual arcade game built with Phaser 3 where the player catches falling stars while avoiding bombs before the timer expires.

Objective
Catch at least 20 stars before the timer reaches zero while avoiding bombs.

Controls
Desktop:
• Left Arrow
• Right Arrow
Mobile / Tablet:
• Drag anywhere on the screen to move the basket.

Installation
npm install
npm run dev

Tech
• Phaser 3
• Vite

Assumptions
• Designed to remain under the 5 MB limit.
• Assets are embedded as Base64 strings.
• Responsive for desktop, tablet and mobile devices.
